# Tarefa 01: Configuração inicial do projeto

## Objetivo

Preparar a base estrutural da aplicação para o MVP 01, escolhendo a stack e a organização inicial do repositório, sem incluir funcionalidades de negócio.

## Pré-requisitos

- Repositório vazio ou sem projeto implementado.
- Aceitação da decisão inicial: React + TypeScript + Vite.
- Definição de que o MVP 01 será local-first e sem backend.

## Arquivos afetados previstos

- package.json
- vite.config.ts
- tsconfig.json
- tsconfig.node.json
- index.html
- src/main.tsx
- src/App.tsx
- src/styles/globals.css

## Critérios de aceitação

- o projeto inicial é criado com React + TypeScript + Vite;
- a aplicação consegue inicializar sem erros de configuração básica;
- a estrutura de diretórios mínima está pronta para receber a biblioteca e a camada de persistência;
- a base visual inicial está organizada para evolução futura;
- nenhuma funcionalidade de negócio ou de screenshots aparece nesta etapa.

## Entregável

Estrutura base funcional do projeto pronta para a implementação do domínio e da interface do MVP 01.
