# Ordem de execução das tarefas do MVP 01

Este diretório organiza as tarefas planejadas para a primeira entrega da biblioteca pessoal de jogos.

## Ordem sugerida

1. [01-project-setup.md](01-project-setup.md) — preparar a base do projeto e a estrutura inicial.
2. [02-domain-and-persistence.md](02-domain-and-persistence.md) — definir o modelo de dados e a camada de persistência local.
3. [03-library-and-empty-states.md](03-library-and-empty-states.md) — montar a biblioteca visual e os estados vazios.
4. [04-game-form-and-details.md](04-game-form-and-details.md) — implementar cadastro, edição, remoção e detalhe do jogo.
5. [05-validation-responsiveness-and-qa.md](05-validation-responsiveness-and-qa.md) — finalizar validação, responsividade e verificação de qualidade.

## Regras de execução

- As tarefas devem ser executadas em ordem de dependência.
- Cada tarefa deve ser verificável individualmente.
- Não deve haver tarefa que dependa de funcionalidade fora do escopo do MVP 01.
- A implementação da próxima etapa deve considerar apenas o resultado da etapa anterior como requisito base.
- A fase de testes é executada ao final, mas também pode incluir testes pontuais durante o desenvolvimento.

## Critérios gerais de conclusão do MVP 01

- funcionalidade principal concluída;
- dados persistidos em LocalStorage;
- experiência visual coerente com a identidade editorial;
- estados vazios, validação e responsividade tratados;
- ausência de recursos fora do escopo nas telas e no fluxo principal.
